# Professional Chatbot Interface

A simple yet polished web interface for a chatbot featuring smooth animations and modern design.

## Preview

Open `index.html` in any modern browser to see the interface in action.

![screenshot](screenshot.png)

## Features

- Clean minimalist layout powered by Google Font **Inter**
- Animated header slide-in and message fade-in
- Typing indicator with bouncing dots
- Responsive design (mobile friendly)

## Usage

1. Clone or download this repository.
2. Simply open `index.html` in your browser.
3. Type a message and press **Send** or hit **Enter**.
4. The bot will respond with simulated replies.

## Customization

- Modify `styles.css` to adjust colors, spacing, or animations.
- Update logic in `script.js` to connect to a real backend or API.
