# Digital Krishi Officer - AI-Powered Agricultural Advisory System

## Overview

Digital Krishi Officer is an innovative AI-powered agricultural advisory system designed to bridge the gap between farmers and expert knowledge. This web application provides instant, accurate, and context-aware farming advice in multiple Indian languages, making expert agricultural guidance accessible to all farmers regardless of their location or literacy level.

## Problem Statement

Farmers often face critical questions related to pests, weather, inputs, subsidies, and market trends—but timely expert advice is rarely accessible. Agricultural officers and helplines are overburdened, and existing services don't scale to support individual needs across diverse regions, languages, and literacy levels.

## Solution

Our AI-powered advisory system allows farmers to ask queries in their own language (preferably Malayalam) and receive accurate, context-aware answers instantly.

## Getting Started

### Prerequisites
- Modern web browser (Chrome, Firefox, Safari, Edge)
- Internet connection for initial load
- Microphone access for voice features (optional)

### Installation
1. Clone or download the project files
2. Open `index.html` in a web browser
3. Allow microphone access when prompted (for voice features)

### Usage

#### Text Queries
1. Select "Text" input method
2. Type your agricultural question
3. Optionally fill in context settings (location, crop, season)
4. Click "Submit" to get AI response

#### Voice Queries
1. Select "Voice" input method
2. Click "Start Recording"
3. Speak your question clearly
4. Click "Stop Recording" when finished
5. System will process and respond

#### Image Analysis
1. Select "Image" input method
2. Click "Upload Image"
3. Select photo of diseased crop or pest
4. System will analyze and provide diagnosis
